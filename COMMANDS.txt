SETUP & CONFIGURATION
────────────────────────────────────────────────────────────────────────────────

Enable Auto-Startup (Windows):
  1. Press Windows key
  2. Type: shell:startup
  3. Copy: ..\run_on_startup.bat into that folder
  4. Restart computer

View Configuration:
  config/settings.py     (Paths, options)
  config/categories.py   (Keywords, rules)

COMMON TASKS
────────────────────────────────────────────────────────────────────────────────

Task: See what files are being organized
  ➜ python dashboard.py

Task: Find a specific file in organized folder
  ➜ python search.py "filename_part"

Task: Check if organizer is working
  ➜ Add a test file to Downloads/
  ➜ Wait 30 seconds
  ➜ Check if it moved to Organized/ folder

Task: See activity log
  ➜ python history.py

Task: Disable auto-startup
  ➜ Press Windows key → Type: shell:startup
  ➜ Delete: run_on_startup.bat from that folder
  ➜ Restart computer (optional)

Task: Re-enable auto-startup
  ➜ Same as "Enable Auto-Startup" above

Task: Add custom categorization rules
  ➜ Edit: config/categories.py
  ➜ Add keywords to appropriate lists
  ➜ Restart organizer: python main.py
