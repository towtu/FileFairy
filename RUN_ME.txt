DO THIS:
─────────────────────────────────────────────────────────────────────────────────

1. Press Windows key + R (or Windows key, type: cmd)

2. Type or copy-paste EXACTLY this:

   cd C:\Users\atila\Desktop\Automations\Organizer\smart-file-organizer && python main.py

3. Press Enter

4. You should see:

   Starting Smart File Organizer...
   Watching: C:\Users\atila\Downloads
   Output to: C:\Users\atila\Downloads\Organized
   Academic Mode: Enabled
   Running in background... (Press Ctrl+C to stop)

5. Leave this running

6. Open ANOTHER Command Prompt window and test:

   echo test > C:\Users\atila\Downloads\lecture.pdf

7. Wait 5 seconds, then check:

   C:\Users\atila\Downloads\Organized\Academics\Lectures\

   ✓ lecture.pdf should be there!

════════════════════════════════════════════════════════════════════════════════

WHY NOT POWERSHELL?

PowerShell interprets Python's print output as commands, causing errors.
Command Prompt (cmd.exe) just displays the output correctly.

════════════════════════════════════════════════════════════════════════════════

WHEN TESTING IS DONE:

Press Ctrl+C to stop the organizer.

Then follow these steps to enable auto-startup:

   1. Windows key → Type: shell:startup → Enter
   2. Find: run_on_startup.bat (in your project folder)
   3. Copy it into the startup folder
   4. Restart computer
   5. Done! Auto-organizes forever
