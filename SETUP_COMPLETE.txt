IF YOU NEED TO STOP IT
─────────────────────────────────────────────────────────────────────────────────

To disable auto-startup:
  1. Windows key → shell:startup
  2. Delete: run_on_startup.bat
  3. Restart computer

To stop it now (before restart):
  • Task Manager (Ctrl+Shift+Esc)
  • Find: pythonw.exe
  • Right-click → End Task
