WHAT IS THIS?
─────────────────────────────────────────────────────────────────────────────
A tool that automatically organizes your Downloads folder into:
  • Academics (lectures, assignments, research)
  • Code (Python, JavaScript, Java, etc.)
  • Documents (Word, Excel, PDF)
  • Images (photos, screenshots)
  • Videos (MP4, AVI)
  • Audio (MP3, podcasts)
  • Data (CSV, JSON)
  • And more...

Plus a live monitoring dashboard to see what's being organized.

3-STEP SETUP GUIDE
─────────────────────────────────────────────────────────────────────────────

STEP 1: UNDERSTAND THE FLOW (5 minutes)
─────────────────────────────────────────────────────────────────────────────
  📁 You download files to: C:\Users\atila\Downloads\
  ↓
  🤖 Organizer automatically detects file type
  ↓
  📂 Moves to: C:\Users\atila\Organized\[Category]\[Subcategory]\
  ↓
  📊 Dashboard shows what was organized

Example:
  lecture.pdf → Organized/Academics/Lectures/Slides/
  my_code.py → Organized/Code/Python/
  screenshot.png → Organized/Images/Screenshots/


STEP 2: ENABLE AUTO-STARTUP (2 minutes)
─────────────────────────────────────────────────────────────────────────────
After you're confident it works:

  1. Press Windows key on keyboard
  2. Type: shell:startup
  3. Press Enter (opens Startup folder)
  4. Find: run_on_startup.bat (in your Organizer project folder)
  5. Copy file into the startup folder
  6. Restart your computer
  7. Done! Now runs automatically

To verify it works:
  • Download a few files to Downloads/
  • They'll automatically move to Organized/ subfolder
  • Optional: Run "python dashboard.py" to see live stats


STEP 3: MONITOR (OPTIONAL)
─────────────────────────────────────────────────────────────────────────────
Anytime you want to see what's being organized:

  1. Open Command Prompt or PowerShell
  2. Navigate to: C:\Users\atila\Desktop\Automations\Organizer\smart-file-organizer\
  3. Run: python dashboard.py
  4. See live statistics (updates every 5 seconds)
  5. Press Ctrl+C to exit

WHAT GETS ORGANIZED?
─────────────────────────────────────────────────────────────────────────────
Files automatically organized by:
  • File extension (100+ supported)
  • Filename keywords (100+ patterns)
  • Academic keywords (subjects, lectures, assignments)
  • File size (only >10KB to ignore temp files)

Examples:
  lecture*.pdf         → Academics/Lectures/Slides/
  assignment*.docx     → Academics/Assignments/Pending/
  *.py, *.js, *.java   → Code/[Language]/
  *.mp4, *.avi         → Videos/
  *.mp3, *.wav         → Audio/
  *.png, *.jpg         → Images/
  *.csv, *.json        → Data/

TROUBLESHOOTING
─────────────────────────────────────────────────────────────────────────────
Files not organizing?
  → Check: C:\Users\atila\Downloads\ (must be this folder)
  → Check: File size >10 KB (too small files are ignored)
  → Check: Is organizer running? (python main.py)

Dashboard shows nothing?
  → Let organizer run for a few minutes to collect stats
  → Then run: python dashboard.py

Want to disable auto-start?
  → Delete run_on_startup.bat from Windows startup folder
     (Press Windows key → Type: shell:startup → Delete file)
